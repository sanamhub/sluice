BLAKE3 hash rate in this browser

Measures how fast one thread hashes with BLAKE3 compiled to WebAssembly, for ADR 0014. Each rate is shown next to 500 Mbit/s, the browser target in docs/performance.md, and 1 Gbit/s. The page reports the numbers and decides nothing.

Three cases per build. In memory hashes bytes already in WASM memory, which is the hash rate alone. Copied in feeds the same bytes from JavaScript in 1 MiB chunks, so it also pays the copy into WASM memory. From a memory-backed Blob reads a Blob that is held in memory through stream(), so it leaves out the disk read that a dropped file pays. The simd build is the one ADR 0014 names, and scalar shows what SIMD is worth.

Optional. It adds a fourth case, From a file on disk, for both builds. Only its size and the times are recorded, never its name or type, and the file is not uploaded. The first read comes from disk and later reads may come from the operating system's cache, so the table says which run was the first read. The page does not try to clear the cache.

Keep this tab in the foreground. Nothing is sent anywhere: the page makes no request except for its own files.

This page is cross-origin isolated, so the host sets COOP and COEP headers. ADR 0014 assumes it does not. Do not publish these numbers as its measurement.
