# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior privately to the address in the repository profile. Reports are handled
confidentially. Maintainers who do not follow the code are removed from the maintainer list.

In short: be decent, assume good faith, and argue about the work rather than the person. Slow and
thoughtful review beats fast and careless merging.
